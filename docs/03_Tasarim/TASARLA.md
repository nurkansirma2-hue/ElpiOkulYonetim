# TASARLA standardı

TASARLA, mevcut proje ve onaylı ana sayfa görsel dili temelinde yeni görsel tasarım üretir; kod değiştirmez. UI_STANDARDI.md okunur. İlgili modülün işlevleri, veri kapsamı ve ekran geçişleri korunur. Örnek veriler tasarım örneğidir. Onaylı görsel sabit referans olur; UYGULA için GORSEL_UYGULAMA.md okunur. Tasarım onayı GitHub yazma izni değildir.
